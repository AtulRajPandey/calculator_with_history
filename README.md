# Calculator with History
A simple Python command-line calculator that performs basic arithmetic operations and stores calculation history using file handling.

## Features
- Addition, subtraction, multiplication, division
- Saves calculation history
- View or clear history
- Command-line interface

## How to Run
1. Install Python
2. Clone the repository
3. Run the program using:
   python calculator_with_history.py

## Usage
Enter calculations in the format:
8 + 8

Commands:
- history
- clear
- exit

## Concepts Used
- Python
- File Handling
- Functions
- Loops
- Conditional Statements
